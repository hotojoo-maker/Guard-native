# 02_docs_文档员

文档维护 + T 调研任务池，由 **`guard-review_质检门控`** skill 的「资料功能」维护（原 guard-doc-audit_资料员 已合并）。

## 子目录约定

| 文件/目录 | 用途 |
|----------|------|
| `CONFLICTS.md` | 文档冲突仲裁记录（按需新建） |
| `T_TASKS/` | 调研子任务池（可由便宜模型独立完成） |

## T 调研任务命名

`T_TASKS/T<编号>_<主题>.md`

例：`T05_8066朋友圈SnsObject类定位.md`

每个 T 任务文件结构：

```markdown
# T<N>_<主题>

## 输入
- 数据/文件路径

## 任务
- 1-3 个具体动作

## 产出格式
- 期望文件/字段

## 验收
- 通过判据
```
