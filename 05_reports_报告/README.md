# 05_reports_报告

阶段性大报告（不是 P 任务日常 result.md）。

## 命名

`TECH_SYNC_SUMMARY_<阶段>_<日期>.md`

例：
- `TECH_SYNC_SUMMARY_v1_第1周.md`
- `TECH_SYNC_SUMMARY_v1_第1月.md`
- `RISK_HISTORY.md` — 风险阻塞历史

## 周报模板

```markdown
# v1 第 N 周 TECH SYNC SUMMARY

## 本周完成
- W1: ...
- W2: ...
- W3: ...
- W4: ...

## KPI 趋势
| 指标 | W1结束 | W2结束 | 当前 |

## 阻塞 / 决策
- ...

## 下周计划
- ...
```
