## 零、最终架构（定稿）

### 普通消息路径
```
LL.add(NotificationItem)
  └─ talker ∈ hiddenIds + isActive()
       ├─ setResult(false)          // 阻止入队
       ├─ 设 blockToken{wxid, ts}
       └─ 执行 NotifyPolicy（仅此一次）
            OFF     → 静默
            VIBRATE → Vibrator.vibrate()
            SOUND   → Ringtone.play()

NM.notify     → blockToken 命中 → setResult(null)    // 只拦，不触发 Policy
in-app bubble → blockToken 命中 → 阻止 show()         // 只拦，不触发 Policy（❓ 待验证）
```

### 语音/视频来电路径
```
NM.notify → voip channel + isActive() → 直接 cancel   // 强制 OFF，不走 Policy
Activity.onCreate → voip/call 模糊匹配 → finish()      // 🟡 备用兜底（未实际触发）
```

**铁律**：LL.add 是唯一决策点，Policy 只执行一次；voip 强制 OFF 不走 Policy；前台 bubble 待验证。
