## ① 大白话

- **授权** = 用户花钱买、服务器发的「使用资格」（绑定 wxid + 设备）。没授权 = 模块装了也不干活（功能灰、密友不藏）。
- 授权 **≠** 口令 `111111`（那只让「设置入口」重新冒出来）；**≠** 显形/隐藏（那是状态机管「现在藏不藏」）。三者各管一摊、别混——这是过去维护犯晕的头号原因。
- **服务器能远程「撤」**：单卡封停/删卡一下发，这台**立刻**断隐私+防封（可被有效授权恢复）。整批版本停用见 §⑥ F.4（注意：当前**不是**即时）。

## ② 五层门控（任一层判停 → 下游放行；互相独立、不可互相替代）

| 门 | 管什么 |
|---|---|
| 入口门 EntryGate | 口令 111111 → 只让「设置入口」可见 |
| 授权门 AuthGate | wxid + 设备 + license → 能不能用功能 |
| 配方门 ConfigGate | 服务器种子解开 registry → release 下敏感隐藏链才生效 |
| 状态门 StateGate | HIDDEN/VISIBLE → 密友过滤生不生效 |
| 风险门 RiskGate | 包/签名被改 → 全静默（SAFE_MODE） |
