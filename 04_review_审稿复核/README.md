# 04_review_审稿复核

由 `guard-review_审稿复核` skill 维护。

## 子文件

| 文件 | 用途 |
|------|------|
| `W<N>_<日期>.md` | 每窗口每天的交接快照（5-10 行）|
| `RETRACTED_CONCLUSIONS.md` | 被撤回的结论（永久保留，标注撤回日期）|

## 交接快照模板（W<N>_<日期>.md）

```markdown
# W<N> <日期> 交接快照

## 今日完成
- ...

## 未完成/卡点
- ...

## 给下一会话
- 读完哪 X 个文件可接上
- 注意点

## KPI 对比
| 指标 | 基线 | 本次 | 增量 |
```

## RETRACTED 模板

```markdown
| 日期 | 原结论 | 出处 | 撤回原因 | 替代结论 |
```
