## 自洽性

### 矛盾 1 (CRITICAL): isVipMode() 逻辑反转 — MomentsFilter.java:82

```java
// 当前（错误）:
if (StateMachine.getInstance().isVipMode()) return;

// StateMachine.java:62: mVipMode = (mState == State.HIDDEN);
// isVipMode() = true → HIDDEN → 应该过滤 → 但当前 return 跳过了！
```

- HIDDEN 状态: isVipMode()=true → return → **不过滤** ← 错
- VISIBLE 状态: isVipMode()=false → 继续 → **过滤** ← 错
