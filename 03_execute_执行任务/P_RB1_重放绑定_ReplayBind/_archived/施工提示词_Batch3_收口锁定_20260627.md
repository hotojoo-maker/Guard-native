## 1. 改动（逐文件）

### SO — `native_core/src/config_crypto.cpp`
- `unwrap_server_seed(k,k_len,nonce,nonce_len)`（**保留现签名**）：
  - **删** Batch 1 双试里的「② 全局 W 回退分支」（`wk = g_wk_lo||g_wk_hi` 那段，整段删）。
  - 只剩：`g_device_mat_len == 32` → `derive_wrap_key(wkd)` → `gcm_decrypt(...)` → 成功且 `seed.size()==32` 存 `g_server_seed`。
  - 无 `dm` / `W_dev` 失败 → `g_server_seed_len=0; return false`（散沙，**无兜底**）。
  - **牙④启用**：unwrap 成功后追加 `if (g_envelope_expiry && g_envelope_expiry <= trusted_now_floor()) { g_server_seed_len=0; return false; }`（过期散沙）。`trusted_now_floor` 取 `LeaseClock.trustedNow()` 下推值（官方授时 floor 防冻，见 `P_AntiBanGate/DESIGN §6`）。
- **删** globals `g_wk_lo` / `g_wk_hi`（全局 W 常量）。
- **新增** globals `g_envelope_expiry`(int64) + `set_envelope_expiry(int64)`（先存，供 unwrap 比对）。
- 注释更新：「Batch 3 收口：W_dev 唯一路径；牙④ expire floor 检查（不折静态 key，a 案）」。**不动** `derive_registry_key`（稳定料 cert+S_rel+device+release 不变）。

### Java
- `core/NativeBridge.java`：新 JNI `setEnvelopeExpiry(long)`（**keep 不混淆**）。
- `net/AuthEnvelopeVerifier.java` / `net/EnvelopeStore.java`：Ed25519 验签通过后，把信封 `expire_at` 经 `NativeBridge.setEnvelopeExpiry` **下推 SO**。
- `ModuleMain.java`：冷启时序确认 —— `bindSigningCert → setDeviceMaterial（已有）→ 验签信封后 setEnvelopeExpiry → unwrap`。
- 注释/文档同步：dm 为空**不再回退全局 W**（Batch 1 时回退、Batch 3 后散沙）；正版必有 `dm`，无 dm = 异常态散沙。

### 工具 + 服务器（服务器侧归 `guard-server_服务器运维` skill，本卡只标接口）
- `tools/kdf_common.py` + `tools/gen_registry_cipher.py`：删全局 W 派生镜像分支，`W_dev` 唯一向量（与 SO 逐字节对齐）。

## 2. 验（负向为主 —— 收口的命门在「该散就散」）

- **host**：`tools/run_native_tests.ps1` 全绿 —— 删全局 W 后 `W_dev` 唯一路径向量 + 域分离 + round-trip PASS；`kdf_self_test` 重 pin 后过。确认全局 W 常量已无引用、编译干净。
- **装机正向（必须上卡）**：正版冷启（已回填 dm + Batch 2 发 W_dev 信封）→ `[hb] registry after seed ... entries=5 ... recipeOk=true` + 密友隐藏不挂；**续约（换新 expire）→ 不自锁、照常 recipeOk=true**（验牙④ a 案不锁正版）。
- **负①（牙③ 通杀堵死）**：A 机信封 `k/n` 搬 B 机（不同 ANDROID_ID）→ 不同 `W_dev` → unwrap 失败 → 现在**无全局 W 兜底** → `registrySummary=scatter` / `isConfigReady=false` / 敏感 hook 不装。
- **负②（牙④ 重放/过期）**：喂过期信封（`expire_at <= trusted_now`）→ SO 拒 → 散沙；**冻结手机时钟**（验官方授时 floor）→ `trusted_now` 仍按 floor 推进 → 照样判过期、不被冻死。
- **负③（无 dm 不误伤回归）**：临时不设 `dm` → 现在直接 scatter（Batch 1 是回退全局 W、Batch 3 后无兜底）。**专门确认正版必有 dm**（`rawAndroidId` 预热成功），避免收口后误伤正常正版。
- `frida_stats` 各项不超红线（unwrap 仅多一次 expire 比较，开销可忽略）。
