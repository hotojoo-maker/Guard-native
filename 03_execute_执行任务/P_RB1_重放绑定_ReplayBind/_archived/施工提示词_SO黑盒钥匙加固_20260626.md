## 0. 目标 + 黑盒边界（只下沉钥匙层）

- **牙③ W_dev（一机一密）**：W 从全局静态明文一把（`config_crypto.cpp` `g_wk_lo/g_wk_hi`）→ `W_dev = KDF(wseg_a/b/c + D_mat)`，`D_mat = SHA-256(ANDROID_ID)` 全 32B。服务器逐台 wrap `S_rel`。治「抽一台 SO 通杀所有机」。
- **牙④ 重放 / 过期绑定（a 案 · 2026-06-26 修正，不折静态 key）**：expire **绝不进静态 registry key**（会自锁）；改为 SO `unwrap_server_seed` 后比 `expire_at <= LeaseClock.trustedNow()`（官方授时 floor 防冻）→ 过期散沙。治「旧 / 过期信封重放」。详见设计稿 §3。
- **黑盒边界（skill 硬线）**：只下沉**钥匙层**（派生 / 验签 / 解密 / 设备·摘要折入）；**策略 / 弹窗 / 影子期 / 时间宽限 / RiskLevel 留 Java**（好调试、可热改、崩溃可控）。**禁止**往 SO 塞策略。

## 1. 铁律（违任一即 BLOCK · 关键钉死，规则全文看 skill）

1. **三端逐字节镜像**：`config_crypto.cpp` ↔ `tools/kdf_common.py`(+`gen_*_cipher.py`) ↔（如有 Java）。改 `derive_*` / `unwrap_*` **先出测试向量 + 三端断言一致**，向量不过**禁止动**。
2. **域分离**：`wseg_a/b/c` 必须 ≠ `seg_a/b/c`（DEBUG 自测断言互不相等）。（牙④ 改 a 案后**不折 key**，原「摘要折入用独立位移常量」作废。）
3. **fail-closed**：错 / 无 `D_mat`、无种子、信封过期 → 散沙（GCM 天然）；**不崩 / 不全开 / 不删数据 / 不破坏原版**（红线 #5/#6）。
4. **改 key 派生 = 全发行线重生成 cipher + 装机回归**（每 `release_id` 各自 regen `registry_cipher.inc` + 验 `recipeOk=true` + 密友隐藏不挂）。
5. **灰度 3 步**（design §5）就位，缺迁移 = 全量正版散沙。
6. **JNI 新方法 keep 不混淆**。
7. **A2 同源隔离**：`D_mat` 只来自 `AuthManager.rawAndroidId(ctx)` 唯一读点；A2 灌给官方包的官方 SSAID **不得**进 `D_mat`。冷启时序 `rawAndroidId 预热 → setDeviceMaterial → unwrap → A2 install`；预热失败则不装 A2（宁可不开防封，不污染设备材料）。
8. **完成前不得宣称「真锁终局」**。

6. 验：`tools/run_native_tests.ps1` 全绿（向量 + round-trip + 域分离 PASS）。

### Batch 1 — 灰度①铺路双试（向后兼容；装机验）

- SO：`unwrap_server_seed` 改**双试**——先 `W_dev`（用 `g_device_mat`）后全局 W（现 `g_wk_lo/hi`）；任一成功即可。
- Java：`AuthManager.computeDeviceMaterial()`（全 32B，与现 8B `computeDeviceHash` 并存）；`ModuleMain` 冷启时序加 `setDeviceMaterial`；`GuardActivation`/`EnvelopeClient`/`GuardHeartbeat` 三类请求带 `dm`。
- 服务器**仍发全局 W**信封。**装机验正版 `recipeOk=true` + 隐藏不挂**。

### Batch 2 — 服务器侧（归 `guard-server_服务器运维` skill，本卡只标接口）

- 逐设备 wrap `S_rel` → `k/n`；`dm` 自校验基准 = **`dm[:16 hex] == device_id`**（禁 `payload.d`，design §2 红线）；`dm` + 信封摘要进 Ed25519 签名覆盖。按已回填 `dm` 的设备改发 **W_dev 信封**，其余仍全局 W。

### Batch 3 — 收口锁定（装机回归）

- 删 `g_wk_lo/hi` + 双试里全局 W 分支（只剩 W_dev）；**牙④ SO 层 `expire_at <= trusted_now` 检查启用**（服务器 expire 进签名 + Java 下推 + SO 比 floor，见 §0 牙④）；服务器停发全局 W。前置：绝大多数活跃设备已回填 `dm`（看板核账）+ Batch 2 稳定一观察窗。

## 4. 验收（design §8 · 负向为主）

- 正向：正版激活上报 `dm` → 服务器按 `dm` wrap → SO `setDeviceMaterial` → `k` unwrap 成功 → `registrySummary ... entries=4`（注：a2.sig 后为 5，见 self-test 计数修） → `recipeOk=true` → 密友照常隐藏。
- 负①（牙③）：A 机 `k/n` 搬 B 机（不同 ANDROID_ID）→ 不同 `W_dev` → unwrap 失败 → `scatter` / `isConfigReady=false` / 敏感 hook 不装。
- 负②（牙④ a 案）：过期信封 `expire_at <= trusted_now`（官方授时 floor）→ SO 拒 → 散沙；正版续约（新 expire）→ 正常不自锁。
- 三端 KDF / round-trip / 域分离向量全 PASS；`frida_stats` 各项不超红线；灰度老设备升级前后正常。
