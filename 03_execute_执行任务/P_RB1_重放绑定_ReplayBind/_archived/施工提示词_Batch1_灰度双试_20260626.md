## 0. 三条硬条件（违任一 BLOCK）

1. **双试必保「全局 W 路径」**：W_dev 失败必回退全局 W（`g_wk_lo`/`g_wk_hi`）。当前服务器**仍发全局 W**，正版必须照常 unwrap → `recipeOk=true`。**绝不删全局 W**（那是 Batch 3）。
2. **`dm` 来自真 ANDROID_ID**（`AuthManager.rawAndroidId` **唯一读点**），**绝不**用 A2 喂官方包的官方 SSAID（A2 同源隔离）。
3. **装机验收必须上卡**：看正版 `recipeOk=true` + 密友隐藏不挂 + `registrySummary ... entries=5`。scatter 冒烟**不够**。

## 1. 改动（逐文件）

### SO
- `native_core/src/config_crypto.cpp` `unwrap_server_seed(k,k_len,nonce,nonce_len)` 改**双试**（保留现签名）：
  - ① 若 `g_device_mat_len == 32`：`uint8_t wkd[16]; derive_wrap_key(wkd);` → `gcm_decrypt(wkd, nonce,12, k,32, k+32,16, seed)`；成功且 `seed.size()==32` → 存 `g_server_seed` + `g_server_seed_len=32` → `return true`。
  - ② ①失败 / 无 dm → **回退现有全局 W 路径**（`wk = g_wk_lo||g_wk_hi` 那段，**逐字保留**）。
  - ③ 两者皆失败 → `g_server_seed_len=0; return false`（散沙，不变）。
  - 注释标「Batch 1 双试：W_dev 优先、全局 W 回退（Batch 3 删全局）」。**不动** `derive_registry_key`。

### Java
- `core/AuthManager.java`：新增 `computeDeviceMaterial(ctx)` = `SHA-256(rawAndroidId)` **全 32B**；与现 `computeDeviceHash`(8B) **共用 `rawAndroidId(ctx)` 唯一读点**（memoize 真值）。注：`dm` 前 8B（16 hex）== `computeDeviceHash` = `device_id`（服务器 Batch 2 自校验基准 `dm[:16]==device_id`，设计稿 §2 红线）。
- `ModuleMain.java`：冷启时序——`bindSigningCert` 之后、**unwrap/`applyServerSeedAndReset` 之前**插一步 `NativeBridge.setDeviceMaterial(AuthManager.computeDeviceMaterial(ctx))`。android_id 拿不到 → 不设 dm（双试自动回退全局 W，**不阻塞正版**）。
- `net/GuardActivation.java` / `net/EnvelopeClient.java` / `net/GuardHeartbeat.java`：三类请求 body 加字段 **`dm`**（32B hex）。服务器 Batch 2 前忽略 → 向后兼容。
