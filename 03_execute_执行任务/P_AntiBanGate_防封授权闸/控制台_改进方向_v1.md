## 0. 一页结论（先看这段）

1. **信息架构**：左侧栏 8 个区（概览 / 设备 / 卡密 / 版本 / 风控影子 / 心跳&KPI / 策略阈值 / 审计）；**设备表为心脏**，点一行右侧滑出**设备详情抽屉**，抽屉里用「**多轨时间轴**」把每个时间段（防封三钟、隐私 72h、心跳、租约、影子、付费宽限）的**进度/剩余/状态**全摊开——这是满足「每段时间都要看见」的核心控件。
2. **视觉方向**：丢掉暗色蓝调 + 渐变卡 + emoji + 阴影，换成**浅底中性「企业运维后台」皮**（纸白底、1px 描边、低饱和点状态、单一克制强调色、等宽数字、扁平无 3D）；另备一套**去饱和暗色**（Grafana/Linear 风，非现在的霓虹蓝）当可选，**主题明暗请指挥拍**。
3. **拿不准要拍的**：①主题走浅底还是去饱和暗色（还是双主题切换）；②emoji 是否全换成单色线性图标 / 状态点；③IA 是否真要扩到 8 区（还是保留设备/卡密/版本 3 页 + 抽屉）；④时间轴是只放抽屉，还是每行也塞一条 mini 时间轴。

> 8 区是「信息越多越好」的满配。**若指挥想先收口**，最小集 = 设备 + 卡密 + 版本 + 设备详情抽屉；其余作为 tab 折叠/后续补。**请拍 IA 范围。**

### 2.2 设备主表列（分组提密度，横向可控）

固定左列：`☐ 选择` · `设备(hash + wxid)` · `形态/版本(官替🟦/共存🟩 + release_id)`
可滚动列分 4 组：
- **身份指纹**：cert 前缀 + schema + **A2 三轴小灯**（签名 / android_id / 包名 各一个状态点）← 能力点 #2
- **信任**：信任阶段（状态点+文字）+ 信任分 vs 及格线（细条，标 60% 占位线）+ 风险分/等级
- **闸 & 时间**：**闸状态**（isAntiBanReady 当前分支 + 当前时间段 + 到下一边界倒计时）/ 心跳（相位 + 上次/下次心跳）/ 租约（型 + 剩余 + 进度）← 满足 #4 的行内浓缩
- **运行**：弹窗状态（无/软引流/登录砸门/影子）/ 最近异常 / 操作(⋯)

点任一行 → 右侧**详情抽屉**。

### 2.3 设备详情抽屉（信息越多越好 + 每段时间详细的「主舞台」）

抽屉 = 一台机的全息卡，分块（手机下变上下堆叠全宽）：

**① 多轨时间轴（核心控件，新造）** — 横向分段条，每轨一行，左标题右「当前/剩余」：

```
防封授权闸(A2)  [0–1h 首装][1–2h 软引流][2–24h 登录砸门][≥24h 解体]   ▲当前 1h12m · 距登录砸门 48m · isAntiBanReady=true
隐私离线宽限    [────────── 72h ──────────]                          已用 6h / 剩 66h · 独立闸·不连坐A2
心跳            [密集2-3m][回落10-30m][稳定1-2h封顶6h][嫌疑10m]        相位=稳定 · 上次 2m前 · 下次 ~54m · CONN 0.18(<0.5)
租约            [短租约 7天 ───●─── 升长租约 30天]                     长租约 · 剩 23 天 · 维持心跳自动续
影子期(如命中)   [───── 7天 不续命倒计时 ─────]                        触发线A/C · 剩 5 天 · 到期不续命
付费断网宽限     [───── 7天 ─────]                                    仅曾授权+断网时出现
```

每段：进度填充 + 当前位置游标 ▲ + 剩余时间 chip + 状态色点。**严格照 SPEC 取值**（1h/2h/24h、72h、7 天、心跳四档、信任 60% 占位），鼠标悬停给「谁判 / 成色」。

**② 能力开关面板（满足 #2「客户端有的都能看/能管」）** — 读 + 管：
- A2 三轴（签名 official_der `18c867f0` / android_id 官方 SSAID / 包名）开关 + 当前值
- 隐私四链（会话/通讯录/朋友圈/搜索）+ 来电拦截 + 通知伪装 状态
- 弹窗源（唯一 RiskPromptController）当前态
- 绑定：wxid + device(=android_id)；解绑按钮（标「仅后台管理员」）

**③ 信任/评分明细**：服务器算分（红线#1，客户端只上报）、各阶段及格线、信任档 tier、升降记录。
**④ 历史/审计**：状态机迁移、心跳曲线 sparkline、异常事件、对该机的历史操作。
**⑤ 操作区**：信任 / 标可疑 / 改授权时间 / 封停 / kill 弹窗 / kill 解体(输 release_id) / 解绑（沿用老 demo 高危二次确认 + 审计）。

### 2.4 其余页（要点）
- **卡密**：保留老 demo 四状态 + 绑定查看 + 批量（改到期/封卡/解绑/补发）；加「关联信任阶段、release_id」。
- **版本**：官替/共存/**管理(后台)** 三轴；每 release 一卡：激活率/信任分布/异常率 + **MD5 身份指纹**（apk/registry/official_der/cert，对齐 SPEC §G）。
- **风控影子**：三触发线 A(蜜罐)/B(未授权超时)/C(人为红线) 分区；影子区**不弹/不红闪/不计告警**，静态可溯（沿用老 demo shadow 语义）。
- **心跳&KPI**：相位分布 + KPI 红线表（带「P18 零点未建/F-22」诚实提示，不宣称安全）。
- **策略阈值**：周期外置一处，全阈值只读展示 + 及格线滑块（标「占位，待 KPI 基线」）+「服务器签名下发」示意。

## 3. (b) 视觉方向

> 北极星：像**真实运维后台 / 真产品**（参照 Grafana / Stripe Dashboard / Ant Design Pro / Linear 的克制感），**不要 AI 模板味**。

### 3.1 配色（低饱和、护眼、专业 · 满足 #5/#6/#7）
**主推：浅底中性「控制台」皮**
- 背景 `#f6f7f9`，面板 `#ffffff`，描边 `#e5e7eb`/分隔 `#eef0f3`
- 文字 `#1f2933`(主) / `#5b6675`(次) / `#8a94a3`(弱)
- 强调色**只用一个**且去饱和：石板蓝 `#3b6ea5`（链接/选中态/主按钮），克制使用
- 状态色全部**去饱和**，只作小圆点/标签文字 + ~8% 极淡底，不做大色块/不发光：
  - 稳定/正常 `#4f8a5b`、建立/注意 `#b8863b`、风险/改包 `#b5524b`（砖红非霓虹）、新设备 `#6b7280`、蜜罐/影子 `#9a7b3f`、授权/信息 `#3b6ea5`

**可选：去饱和暗色皮**（Grafana/Linear 风）——底 `#1b1e24`、面 `#22262e`、描边 `#30353d`，同款低饱和状态色。**非**现版的高饱和蓝渐变。

### 3.2 字体 / 间距
- 字体：系统无衬线（PingFang SC / Microsoft YaHei / Segoe UI）；正文 13–14px；**字重只用 400/500/600**（去掉 800 黑体的「重 hero」感）
- **数字/ID/hash/时间一律等宽 + 表格数字对齐**（`font-variant-numeric: tabular-nums`）——运维后台的专业感来源
- 间距 8px 栅格；表格行高 36–40px（密但不挤）；区块内边距 16px

### 3.3 组件（扁平 · 满足 #6）
- 卡片/表格：**1px 描边 + 分隔线**代替阴影；**无渐变、无玻璃模糊、无 3D**；圆角 6–8px（适度）
- 阴影**只在浮层**（详情抽屉 / 弹窗 / 下拉菜单）用一层极淡投影做层级，别处不用
- 图标：**emoji 全部退场**，换**单色线性图标**（内联 SVG）或**状态圆点 + 文字**；阶段不再用 ⚪🔵🟢🟠🔴，改「色点 + 名称」
- 无大 hero、无居中营销排版；概览页 = 顶部细 KPI 条（左对齐）+ 密集卡，不堆中央巨标题
- 数据可视化：细条 / sparkline / **分段时间轴 gauge**，单色系、扁平

### 3.4 响应式（满足 #1）
- ≥1200px：左栏 + 主区 + 右侧抽屉三栏
- 768–1200px：左栏收成图标条；表显主列、次列进抽屉
- <768px（手机）：左栏→底部 tab；**表格降级为「卡片列表」**（一台机一张卡，关键字段竖排）；抽屉→全屏页；操作按钮 ≥44px 触控热区；时间轴竖向堆叠

## 6. 不推翻的既定决策（照 DESIGN/SPEC 原样展示 · 给指挥吃定心丸）

- 三钟口径 **1h/2h/24h**（C81 拍板，覆盖旧 72h/2h）；**72h 是隐私线**、与防封无关、独立计时不连坐。
- **两闸独立**：防封 `isAntiBanReady`(A2) 与 隐私 `isActive/isConfigReady`，各开各的、互不散沙——UI 用两条独立轨，不画成一条。
- A2 三轴（签名/android_id/包名）、official_der MD5 `18c867f0…`、设备绑定 wxid+device、解绑仅后台、服务器权威/客户端只降级——照 SPEC 标注。
- 惩罚 = **暗记 + 影子租约 + 到期不续命**（不立刻 kill/封）；影子区**默不作声、仅审计可溯**。
- 诚实缺口照标：60% 占位、P18 KPI 零点未建(F-22)、登录砸门弹窗实现锚点缺、服务器下发协议待 S9 ——UI 上以「占位/设计only/待验证」角标呈现，不伪装成已落地。
- demo 纪律不变：纯前端假数据、不连服务器、不动主仓/核心代码（GuardRuntime/SO/auth.db）。

## 7. 拿不准 · 请指挥拍板（定了我再进第 2 步）

1. **主题明暗**：浅底中性（我推荐，最「真后台」最护眼）／去饱和暗色（Grafana 风，长时间盯屏友好）／两套切换？
2. **图标方案**：emoji 全换单色线性图标 + 状态点（更专业、工作量略大）／保留极少量低饱和字符标？我推荐前者。
3. **IA 范围**：做满 8 区／先收口为「设备+卡密+版本 + 详情抽屉」其余后补？（决定第 2 步工作量）
4. **时间轴密度**：只放详情抽屉（干净）／每行也塞一条 mini 时间轴（更密、更重）？
5. **管理(后台)轴**：版本页是否纳入「管理/后台」自身一行（SPEC §F 三轴之一），还是本期只做官替/共存两形态？
