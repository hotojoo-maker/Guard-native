## 判定图例

- **registry**：`已接线`=Filter 走 getRecipe / `挂空`=registry 有字段但 Filter 没读 / `无`=registry 没有 / `稳定`=非混淆 FQCN，不收。
- **存活**：✅=HOOK_MAP L1 实证活 / ❌=证伪·废弃 / ❓=未在 HOOK_MAP 确认，需 L1。
- **动作**：`✓已归一` / `A3-2 接线`（registry 已有，接 getRecipe + 撤内联）/ `A3-3 补+接`（registry 无，核验存活后补进再接）/ `不收`（稳定 FQCN/死锚/越界）。
