## ② 能骑 = ✅ L1（既有，共存/测试包 mn）+ 主号安全说明

**既有 L1（防封官 skill §9 / dimmod_v2 SPOOF，2026-06-19，com.tencent.mn）**：LSPosed 冷启动把 `getPackageInfo(self).signatures[0]` 喂官方 DER 后，**`c$p.ad` 实读到 `md5=18c867f0 len=751`（喂前 `e89b158e`）** → 咽喉**可骑**（c$p 读到的就是我们注入的值，未绕过 Java）。

**本轮为什么不在官方包上做 marker 覆盖（主号安全）**：

- 能抓证据显示，`c$p.aa/ad/af` 读到的签名**直接进 `toProtoBuf → network` 上报**。
- 在**官方包（主号）**上把返回改成假 marker = 让官方包**上报一个非官方签名**（签名是「唯一硬判别键」）→ 主号有风险（官方怎么判我方读不到、不预测）。违任务「用测试号别拿主号」。
- 在官方包喂「官方 DER」则是 no-op（本就官方），证不出覆盖生效。
- → **有意义且安全的能骑复证只能在共存/测试包 mn 上做**（喂官方 DER，观察 `e89b158e → 18c867f0` 翻转）。这正是既有 L1 的做法。

**结论**：能骑已 L1 坐实（mn）；如需本轮新鲜复证，应在 **测试包 mn + LSPosed 冷启 + 喂官方 DER**（安全方向）跑，**不在主号官方包做 marker 覆盖**。
