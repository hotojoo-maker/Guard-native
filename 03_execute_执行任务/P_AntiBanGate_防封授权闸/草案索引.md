## 一句话（这事到底在干嘛）

**防封 = 让官方包相信「我是官方正版本人」**——它查的就是「身份证」（签名）。我们的活 = 在它查身份证的唯一咽喉口**灌官方值**（签名 / 设备编号 / 包名都报官方），它一看「干净的官方」就不把号判异常；**再顺手借官方的眼睛**盯这张身份证有没有被换——被换了（有人破解白嫖）就散沙。环境（root / 解锁那些）官方自己读、我方不碰。

## 5. 重设计待办（A2 三轴 → guard_native 落点）

> 详见研究线 §十七对照表 + 配方卡 isAntiBanReady 真值表；本节只列骨架。

1. **签名轴**：扩 `ModuleMain.bindSigningCert()` → `getPackageInfo(self, GET_SIGNATURES | GET_SIGNING_CERTIFICATES)` afterHook 喂官方 DER（751B）。
2. **android_id 轴**：同模块 hook `Settings.Secure.getString(_, "android_id")` 喂本机官方 SSAID（`ssaid_calc.py` 现算）；**连带签名轴自洽**；我方 device 读不被污染（同源问题 → A2 v1 重设计解，参旧 v0 自读闸 / memoize 思路）。
3. **包名 / 路径轴**：同 hook 选择性喂官方包名 + 路径（仅 normsg / bu5 caller，不全局）。
4. **授权闸**：`GuardRuntime.isAntiBanReady()`（现仓无，须新建）挂 A2 install 处；吊 `EnvelopeStore` + `LeaseClock` + 影子租约（配方卡 §A 真值表）。
5. **时序铁律**：A2 install 冷启动 LSPosed 注入、晚于 device 首读；作用域勾实际出货包名。
6. **验收**：两机 D1（d 各异且读真值）+ frida L1（官方包读官方 / 我方读真值）+ 隐私四链回归 + KPI 红线。
