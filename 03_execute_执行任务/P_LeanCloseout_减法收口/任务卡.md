# 任务卡 · 防破解减法收口（LeanCloseout）

> **用法**：本卡 = 单一完整交接文档。**假设原 AI 掉线，新 AI 只读本卡 + §3 指向的真源即可接手全部工作**（总指挥角色见 §1、现状+总图见 §8）。整段粘进新对话即可。
> **本卡边界**：只写「工单 + 约束 + 顺序 + 现状」；机制/设计思想一律**指过去、禁复写**（违单一真源）。
> **接手第一步**：先读 `DESIGN.md §0` + 网络安全官 skill + 授权检查官 skill + 本卡 §8 现状，再动手。

---

## 0. 最高原则（压一切）

1. **用户零代码**：用户只拍「是/否/方向」+ 插手机让 AI 装机 + 读大白话报告。**不写码、不读码、不背「改 X 要改 Y」**。
2. **AI 可接续**：任何新会话照本卡就能接手，不用用户重新解释。
3. **机器验证**：对错靠「测试向量 + 装机 `PHASE*_VERIFY PASS` + gen 脚本」，**不靠用户审代码**。

## 1. 人机分工 + AI 总指挥操作手册

| 谁 | 干什么 |
|---|---|
| **用户** | 拍是/否、定方向、插手机让 AI 装机、看大白话报告 |
| **AI（你=总指挥）** | 派 worker 提示词 + 双角色审查 + 抓装机 L1 日志 + 落 worklog + 守单一真源；**不在主对话亲手写全部代码，给 worker 派活、自己审+解释** |
| **机器** | 测试向量 / 装机 PASS / 构建脚本自动生成 —— 代替「人审码」 |

**驱动循环（每一步照走）**：
1. 派**只读侦察** worker（并行，各写各的 `recon/Rx`）核现状 → 收报告。
2. 出【安全官改前审查】+【授权检查官 9 项】（或 worker 出、你核）。
3. **用户拍是/否**（大白话呈现，用户零代码）。
4. **git 快照（git 保姆）** → 派**改码** worker（串行）。
5. 用户装机 → 你判装机 log（含 jadx release 搜不到名 + 无种子 scatter）。
6. 落 worklog L1 + 回来**更新本卡 §8**。

**并发铁律**：侦察并行（只读、各写各文件、不互踩）；改码**同时只一个 worker**（防撞同文件）；侦察只读 → 可与改码并行。**本卡只总指挥（你）一个写者**，worker 只写自己的 `recon/`、`worklog.md`、`*_install_*.log`（防多写冲突；worker 别动 §8）。

**沟通铁律**：只走 Vchat 给用户**大白话**；用户只拍是/否；结论标 L1~L4；**不瞎猜（G1），无 L1/L2 证据不下结论**。

**worker 提示词模板**：角色（执行 / 只读侦察）+ 先读本卡 +`DESIGN §0`+ 安全官/授权检查官 skill + 任务 + 绝对不做 + 流程 + 写到哪个文件 + 红线（只读则「只读不改、标等级」）。

## 2. 目标（一句话）

防破解靠「减」不靠「加」：**归一消重复 + 砍半成品 + 最后删明文（绑 V3）**；4 大动脉粗粒度**不拆细、不加机制**。
