# 03_execute_执行任务

P 任务执行目录，每个 P 任务一个子目录。

## 命名

`P<编号>_<主题>/`

例：`P15_脚手架/` `P16_朋友圈Proto/`

## 子目录约定

```
P<N>_<主题>/
├── research.md     调研记录（如有）
├── result.md       完成报告（必有）
├── scripts/        本任务专用脚本
└── logs/           运行日志 / KPI 对比
```

## result.md 模板

```markdown
# P<N>_<主题> 完成报告

## 完成清单
- [x] 子任务 1
- [x] 子任务 2

## 产出文件
- src/.../X.java
- ...

## KPI 对比 (frida_stats baseline vs after)
| 指标 | 基线 | 本次 | 增量 |

## 验收结果
- ...

## 风险
- ...

## 交接
- 下一步: ...
- 依赖此任务的下游: W2/W3/...
```

## 关闭后

P 任务关闭 30 天后由资料员搬到 `../07_archive_归档/`
