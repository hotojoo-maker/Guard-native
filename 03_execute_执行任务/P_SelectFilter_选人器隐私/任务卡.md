## 一句话

隐藏态时，发朋友圈「谁可以看 / 不给谁看」的选人器（选择朋友 / 选择标签 / 从群聊导入）**自动过滤密友 + 密群**，杜绝隐私暴露。门控复用 `StateMachine.isActive()`——**显形态加密友不受影响**（加密友必在显形态，`isActive()=false` 自动不过滤，不冲突）。

---

## 背景（L1 已证 2026-06-30）

- 现有 `ContactFilter` 只管「通讯录 tab」（`fc5.g`），**不覆盖**发圈选人器。
- 选人器 = `com.tencent.mm.ui.contact.SelectContactUI`（我们加密友 `ContactImportGuard` 也用它，靠 `isActive()` 区分场景）。
- 列表 = `ListView`（父类 `MMBaseSelectContactUI.d`）。
- 好友 item 类 = `com.tencent.mm.ui.contact.item.u`（adapter `getCount`=2884）。
- **wxid 路径** = `item.u` → 字段 `a.A`（`com.tencent.mm.storage.z3`）→ `z3.c1()`（与 `ContactFilter` 同类同取法，**可复用**）。
- `item.u` 另有 `a.y` / `d.r` = 微信号 alias（如 `as897857706`）。
- `P` 字段 = `ArrayList<String>` 排除名单（`weixin`/`filehelper`/`gh_*` 公众号/含 `wxid_`）→ **备选方案**：往 `P` 加密友 wxid 也能排除。

## 目标（Done 定义）

1. **探到填充点**：好友数据进 adapter 的 backing List（`addAll` / `setData` / 构造），定 hook 点。
2. **新建 `SelectContactFilter`**（对标 `ContactFilter`）：`isActive()` 时按 `z3.c1()` 移除 `Bridge.allHiddenIds()`（密友 ∪ 密群）。

4. **入口分批**：先「选择朋友」（`SelectContactUI` 个人好友）；「从群聊导入」（`GroupCardSelectUI`）+「选择/从标签导入」（标签类 `NewSnsLabelUI`）后续。
5. **装机 L1**：隐藏态选人器不见密友/密群；显形态加密友正常。
