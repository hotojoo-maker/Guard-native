# P_SelectFilter — 发圈选人器隐私过滤

> 状态：✅ 装机确认 2026-06-30（Vchat guard_native-MMK13）
> 实现：`src/main/java/com/ghost/assist/moduleD/SelectContactFilter.java`
> 接入：`ModuleMain.install` (app classLoader)

---

## 一句话

隐藏态时，发朋友圈「谁可以看 / 不给谁看 → 选择朋友」选人器自动过滤密友 + 密群。门控 `StateMachine.isActive()`，显形态加密友不受影响（`ContactImportGuard` 走显形态）。

---

## 实现（最终方案）

- **Hook**：`com.tencent.mm.ui.contact.h0.s()` `beforeHook`
- **反射**：类层级找名为 `m` 的 `ArrayList`（= `a5.m`，h0 的父类字段 `f188236m`）
- **注入**：隐藏态时往 `m` `addAll(Bridge.allHiddenIds())`（密友 ∪ 密群，去重）
- **生效**：s() 自身按 m 排除 cursor row → 选人器列表天然不显示密友 / 密群（绕开 s() 黑盒，无需手动 notify / 重查）
- **门控**：`StateMachine.isActive()`；显形态直接 return
- **稳健**：全程 `catch(Throwable)`（F-25），Field 缓存（`sExcludeField`），用 app `ClassLoader`（Tinker 运行时类）
